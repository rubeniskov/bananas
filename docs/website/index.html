A NAS for your Banana Pro.

Yocto-based NAS distribution for the BPI-M1+. Web admin, NFS, live LCD dashboard, cloud sync — all on one SD card.

Read the docs → ★ GitHub
  • NFS server with web-managed exports — no /etc/exports edits
  • Live LCD tiles — CPU, memory, network, disk, temperatures, all on the on-board panel
  • Cloud sync to Drive, Dropbox, OneDrive, S3, WebDAV via rclone
  • Reproducible bake from pixi run build — every dep pinned
